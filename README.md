# CHIP8 EMULATOR

This project emulates the CHIP-8 "theorical" CPU / Virtual Machine.

### Stack

- Vite
- TypeScript

### Dev

- ROM directory: `public/roms`
- Update ROM list: `node ./scripts/buildRomListJsonFile.js`
- npm install
- npm run dev

### Deploy

- deploy to github pages: `npm run deploy`
