CHIP8 EMULATOR

Vite + TypeScript

 

 

 

Instructions

  • Select a ROM in the dropdown menu
  • Press LOAD to copy the ROM into memory
  • Press START to begin execution, or CYCLE to execute a single instruction
  • Press RESET to clear the memory and reset the emulator
