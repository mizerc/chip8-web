CHIP8 EMULATOR

Vite + TypeScript

 

 

 

Instructions

  • Select a ROM in the dropdown menu.
  • Press LOAD to copy the ROM from disk to CHIP-8 memory at 0x0200.
  • Press START to begin execution, or CYCLE to execute a single instruction
  • Press RESET to clear the registers and memory; so you will need to press LOAD and START/CYCLE again to continue execution.
  • The control panel has sticky positioning and remains visible when scrolling to allow you to see the register or memory while cycling the CPU.
  • If you press CYCLE while the emulator is running, it will execute a single instruction and then pause.
  • The clock dropdown selects the FPS of the application loop. The emulator runs at hardcoded 1 cycle per frame.
